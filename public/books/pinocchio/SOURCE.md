# Pinocchio Chapter 1 sources

- Text: *The Adventures of Pinocchio* by Carlo Collodi, translated by Carol
  Della Chiesa, Project Gutenberg eBook #500.
  https://www.gutenberg.org/ebooks/500
- Audio: Chapter 1 read by Sherry Crowther for LibriVox, distributed through
  Project Gutenberg eBook #19516.
  https://www.gutenberg.org/files/19516/19516-index.html

Project Gutenberg identifies these source items as public domain in the United
States. The deployed lesson omits the LibriVox introduction, retains the human
narration, and uses manually corrected text aligned to locally generated speech
timestamps.
